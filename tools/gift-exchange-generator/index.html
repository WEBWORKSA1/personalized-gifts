Gift exchange name generator

Draw names, set who cannot draw whom, and send private links. No sign-up.

Optional
One name per line, at least three people.
Who should not draw whom

    Useful for couples or people who share a home. Each rule works one way; add it twice for both directions.

    Private links

    After the draw, each person gets their own link. Only that link shows who they are buying for.

    How to use it

    1. List everyone

      Type one name per line and add any rules about who cannot draw whom.

    2. Draw names

      The draw happens in your browser. Nothing is uploaded or stored on a server.

    3. Send the links

      Copy each person’s private link and send it by message or email. The link reveals only their own match.

    Questions people ask

    Can the organiser see who has whom?

    Not unless they open someone else’s link. The results list shows names and links, not matches.

    Do participants need an account or email?

    No. Each person only needs their link.

    What if someone loses their link?

    Links are not stored anywhere. Keep the list of links until the exchange is over, or run the draw again.
