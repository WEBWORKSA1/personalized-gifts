How to use it

  1. Choose a layout

    Classic puts the surname larger in the centre. In order keeps letters one size. Couple and Two names are for pairs.

  2. Type the names

    Full names are fine. The maker takes the first letter of each and arranges them by the rule for that layout.

  3. Style and download

    Pick lettering, a frame and colours, then save a PNG for printing or an SVG for cutting and engraving software.

Questions people ask

What order do the initials go in?

With a larger centre letter: first, surname, middle. With equal letters: first, middle, surname. The maker does this for you.

Can I use the monogram commercially?

Yes. The design is yours. The typefaces are open-licensed fonts that allow commercial use.

Which file should I download?

PNG for printing and documents. SVG for cutting machines, lasers and embroidery digitising, because it scales without blurring.
